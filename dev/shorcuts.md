# Aseprite

* `I` : pick color
* `B`: pencil (brush)
* `G`: bucket paint
* `M`: select rectangular
* `Q`: Lasso tool
* `U`: draw rectangle (push again for filled)
* `Control + Shift + I`: convert to indexed colors
* `Control + E`: export as sprite sheet
* `T`: trim (custom shorcut)
* `Shift + S`: snap to grid
* `Control + '`: show grid

# Vscode

* `Control + P`: open files by name (@ for methods on file)
* `Control + Shift + P`: command palette
* `Control + Shift + F`: search on all files of project
* `Control + B`: show/hide file explorer
* `Control + J`: show/hide terminal
* `F12`: jump to definition
* `F2`: rename and refactor symbol or function
* `Control + Enter`: on file selected, open on the side
* `Control + Shift + B`: run default build task

# Tiled

* `B`: on tiles: brush
* `F`: on tiles: fill
* `R`: on tiles: rectangular select
* `left click`: on tiles with brush: get actual map tile
* `S`: on objects: select object
* `R`: on objects: create rectangle object
